# Индекс постоянного контекста

Кто владеет каким вопросом и куда идти за фактическим состоянием. Это не журнал
задачи, не снимок PR и не копия процедур скиллов.

## Как пользоваться

1. Прочитай корневой [`AGENTS.md`](../../AGENTS.md) — постоянные ограничения.
2. Определи область вопроса и открой только относящийся к ней документ-владелец.
3. Проверяй предположения по фактическому состоянию рабочей копии, а не по этому
   индексу.
4. Не заводи здесь второго владельца процедуры: сначала `AGENTS.md`, затем
   документ-владелец из таблицы. Процедура дублируется только ссылкой на неё.

принадлежат самой задаче и внешним владельцам (Ponytail — методология и
независимое ревью, а не источник полномочий). Второй владелец процедуры здесь не
заводится.

## Что здесь не хранить

- номер текущего PR, имя ветки, SHA и статусы проверок;
- временные результаты ревью, сырой вывод CLI, журналы итераций;
- локальные пути и имена аккаунтов;
- дубли процедур скиллов — публикации, цикла CodeRabbit, формата отчёта: они
  принадлежат своим файлам, здесь только ссылки;
- снимок описания PR и его содержимое;
- доменные планы и заглушки несуществующих документов.
